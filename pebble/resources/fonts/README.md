# Local font setup

Camino Guard can use **Megafont** by **GeronimoFonts** for the `NEXT STOP` area, matching the original Pebble *past-present-future* watchface.

The font's bundled FontStruct license permits personal/non-commercial use but prohibits redistribution, so `megafont.ttf` is intentionally not committed to this repository.

For a local build, obtain your own licensed copy of `Megafont.ttf` and place it here as:

`pebble/resources/fonts/megafont.ttf`

The source watchface uses the same font as `FONT_MEGAFONT_22`. Original attribution: GeronimoFonts — Megafont — FontStruct fontstruction 982790.
